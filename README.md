# Rite

End-to-end encrypted notes for Android and the web, with every feature included and sync
through storage you choose: your MEGA drive, or any compatible server.

Rite is based on [Standard Notes](https://github.com/standardnotes/app) and is licensed under
the GNU AGPL v3. See **[RITE.md](RITE.md)** for how to get the Android app, sync with MEGA, add
your logo, and build it yourself. The original Standard Notes README is kept in
[README.standardnotes.md](README.standardnotes.md).
